# NetFix VPN

Официальные сборки приложения **NetFix VPN** — [netfix.app](https://netfix.app).

Здесь публикуются только готовые сборки (вкладка **Releases**). Исходный код приложения закрыт.

## Платформы

| Платформа | Где взять |
|---|---|
| Android (телефоны и планшеты, Android 7+) | APK в [Releases](../../releases), скоро — RuStore и Google Play |
| Android TV и приставки | тот же APK |
| iPhone и iPad | скоро — TestFlight / App Store |

## Как установить на Android

1. Скачайте `NetFix-<версия>.apk` из последнего [релиза](../../releases/latest).
2. Откройте файл и разрешите установку из этого источника.
3. Войдите в аккаунт NetFix по почте, через Telegram или Google — подписка подключится сама.
   Новым пользователям сервер выдаёт пробные 7 дней.

Проверить подлинность файла можно по SHA-256 из описания релиза.

## Возможности

- Протоколы VLESS (Reality, XHTTP, WS, gRPC), VMess, Trojan, Shadowsocks, Hysteria2 на ядре Xray.
- «Авто» — самый быстрый сервер, водопад уровней и автопереключение при сбое.
- Обход по стране, свои сайты напрямую, блокировка рекламы.
- Android: раздельный туннель по приложениям, плитка в шторке, виджет, автозапуск.
- 17 языков.
